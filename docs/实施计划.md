## 验收门槛

- `npm test` 400/400 通过；
- 34 款车型均存在主 GLB + LOD，且都使用 `KHR_draco_mesh_compression`；
- 目录中的零件数、三角面、体积与实际文件一致；
- 12 种车漆与自定义底色在浏览器中逐一可用；
- 5 个视角预设的相机均落在车库墙内，前/后/侧/顶/45° 构图可读；
- 轮胎下缘与车库地面同面，无嵌入、无悬空；
- 页面默认不出现外部网络请求，断网后仍可加载 `vendor/` 与 `assets/`；
- 车漆、460ms 过渡、悬停高亮、爆炸视图、视角预设、车型库逐项浏览器验证；
- 10 位人物都能加载并在城市里行走 / 奔跑 / 跳跃，15 段动作全部可播放，出生点可见；
- 相机拉到 45 m 时车库玻璃幕墙与立柱不消失，顶视图仍不挡车；
- 车库 +X / +Z 两侧无幕墙、人物可从正面走进车库，−X / −Z 墙、货架、工作台与整车均为实体；
- 21 件 CC0 道具全部带 Draco、总 < 8 MB，落地高度与货架层板一致，两两占地不重叠；
- 17 fps 下跳跃仍然 ≥ 0.9 m、奔跑段速 ≥ 9 m/s（1/120 s 子步）；
- 45° 主视角 ≥ 45 FPS（动态分辨率），draw call ≤ 250、三角面 ≤ 50 万；
- 城市 GLB ≤ 6 MB，远景环在中心附近不参与渲染；
- 车模 / 道具无 `transmission` 材质（避免整帧透射通道）；
- 试驾：1/120 s 子步，2.5 s 内 0 → ≥60 km/h，手刹 1 s 内从 70 km/h 停住，撞墙不穿透；**进入试驾后车停在原位、不给油不动**，停稳才能按 `E` 下车；
- 举升机：降下时不可见且不参与碰撞，升起 1.5 m 后车底完全可见，「底」视角能拍到举升臂与底盘；
- 拍照：8 滤镜可用，PNG 与 WebM 都能下载；人物互动只保留车旁 `E` 上车，三种摆拍姿势与车门开合不再出现；
- `android/` 下不存在 APK；
- 不提供安装包：本地开发直接用浏览器（项目定位是个人本地使用，不发布、不分发）。
