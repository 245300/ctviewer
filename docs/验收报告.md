## 6. 已知限制

1. 不提供安装包：本地开发直接开浏览器（不发布、不分发）。
2. 9 款赛道/超跑来自未声明许可的第三方仓库，仅限个人本地使用，不得对外分发。
3. BMW M3 G80、McLaren GT3、Ford Mustang GT3 为烘焙贴图资产，无独立车漆材质，车漆选择器在这些车型上禁用。
4. `assets/models` 约 91 MB（34 款 + LOD），首次切换车型需各自下载；城市 4.5 MB、人物每人约 0.5–0.8 MB、动作库 1.6 MB 只下一次。
5. 10 位人物来自本机 Unity 工程内《少女前线 2：追放》素材，15 段动作来自 Mixamo，均未随文件声明可再分发许可，**仅限个人本地学习**，不得对外分发。
6. 城市探索的碰撞是 1 m 占位网格 + 车库 −X / −Z 两面墙 + 31 个家具占地盒 + 整车包围盒：不区分楼层高度，人物只能在广场、街道与车库地面行走；车库 +X / +Z 完全开放，可以直接走进去，但家具与车都是实心 AABB，不能爬坡、上车顶或钻进车底。
7. 动态分辨率会把渲染比例降到 0.55–1.0（当前机器约 0.76），画面在近看时略软；需要绝对清晰时用 `?dpr=1`（约 38 FPS）或 `?q=high&dpr=1`。
8. 城市已减面到 19.2 万面并把贴图降到 512²，街景近看会比原来的 2048² / 33.7 万面略简；当前视角（车库内、广场、远景）复核无可见差异。
9. 试驾是街机运动学模型，不是刚体物理：没有坡度 / 悬挂压缩 / 轮胎形变，碰撞只在 XZ 平面（不区分楼层与高度），城市里的台阶与路缘会被当作平地；撞墙时沿墙滑动而不是变形。下车后车辆固定回到展位，不支持把车停在城里过夜。
10. 拍照滤镜是 CSS / Canvas 2D 滤镜，只用于预览与导出，不改变 WebGL 渲染本身；录像上限 10 s、最高 1920 宽、8 Mbps，录制时 2D 画布叠加滤镜会增加一部分 CPU 开销。
11. 两柱举升机把整车（含车轮）一起抬起，不复现悬挂下垂 / 轮胎离地；降下时举升机整组隐藏，这是为了避免立柱挡住侧视，不是物理上真的消失。
